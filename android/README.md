# Искра — Android-приложение

Kotlin + Jetpack Compose

## Что уже есть

- Список чатов
- Создание нового чата
- Экран чата с сообщениями
- Отправка сообщений на бэкенд
- Тёмная тема
- Подключение к API (Retrofit)

## Как открыть и запустить

1. Установи **Android Studio** (Hedgehog или новее)
2. Открой папку `android` как проект
3. Дождись синхронизации Gradle
4. В `ApiClient.kt` укажи адрес бэкенда:
   - Эмулятор: `http://10.0.2.2:8000/`
   - Реальный телефон (одна Wi-Fi сеть): `http://IP_твоего_компьютера:8000/`
5. Запусти бэкенд (`uvicorn app.main:app --host 0.0.0.0 --port 8000`)
6. Нажми Run в Android Studio

## Важно

- Для эмулятора `10.0.2.2` = localhost компьютера
- На реальном устройстве бэкенд должен слушать `0.0.0.0`, а не только `127.0.0.1`
- Нужен интернет-разрешение (уже есть в манифесте)
- Иконка пока стандартная — добавим позже
